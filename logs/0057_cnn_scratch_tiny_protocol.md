# ScratchTinyCNN 从头训练预检协议

## 目的

检验一个不使用 ImageNet 或其他预训练权重的小型卷积神经网络，是否能在白族图案六分类任务上学习到有效特征。该实验与预训练 ConvNeXt-Tiny 阶段 A/B 分开记录，不替换原有结果。

## 固定数据边界

- 固定划分：434 张训练图、93 张验证图、93 张测试图。
- 本实验训练期间只实例化训练集和验证集；测试集不实例化、不读取、不评估。
- 类别顺序保持 `data/splits.json` 中的六类顺序。
- 训练和验证图片哈希在启动时逐张核验。

## 模型

`ScratchTinyCNN`：四个卷积阶段，通道数为 16、32、64、128。每个阶段包含两层 3×3 Conv-BN-ReLU，随后使用 2×2 最大池化；最后使用自适应平均池化、Dropout(0.3) 和六分类线性层。

- 输入：RGB 224×224。
- 参数量：约 294,774。
- 所有参数随机初始化且全部参与训练。
- 不加载 ImageNet、DINO、SigLIP、Qwen 或其他预训练权重。

## 训练设置

- AdamW，学习率 `0.001`，权重衰减 `0.001`。
- batch size 16，最多 50 轮，CosineAnnealingLR，早停 patience 10。
- 损失：普通交叉熵，不使用类别权重和 label smoothing。
- 输入预处理沿用 CNN 基线：保持宽高比缩放、白色补边、轻微颜色/仿射增强。
- 开发种子 42；确认种子为 42、43、44、45、46。
- 选择指标：验证集 Macro-F1。

## 执行顺序

1. 先运行 seed 42 的一轮预检，确认损失有限、参数确实更新、验证集完整评估、`test_evaluated=False`。
2. 预检无异常后，从 seed 42 的 checkpoint 继续完整训练，并从头运行 seed 43–46。
3. 汇总五个种子的最佳验证 Macro-F1 及均值/样本标准差。
4. 在模型和超参数锁定前不运行测试集。
