# 0050 — 剩余 CNN 确认实验一键运行

日期：2026-11-08（America/New_York）

为加快实验，新增 `scripts/run_remaining_cnn_confirmation.py`。它依次处理 seed 44、45、46，并在每个种子内自动完成：阶段 A 至早停、阶段 B 无更新检查、阶段 B 至早停。seed 44 已完成阶段 A 且阶段 B 已有第 1 轮，因此会自动跳过阶段 A、复用已有检查，并从阶段 B 第 2 轮继续。

脚本在每个 epoch checkpoint 边界可恢复：重新运行时，已满足早停/最大轮数的阶段会跳过，存在但未完成的 `last.pt` 会自动恢复，不存在的阶段才从头开始。任何子命令返回非零状态时总控立即停止，不会静默跳过失败。

安全边界：只接受锁定 seed 44–46；复核阶段 A/B 配置 SHA256；每个确认种子使用各自的阶段 A 最佳 checkpoint；阶段 B 前必须存在且仅存在一份对应 seed 的无更新检查报告；不实例化或评估测试集。全部完成后只汇总 seed 43–46 的验证 Macro-F1 均值和样本标准差，并保存小型 JSON；不生成测试成绩。

先用 `--dry-run` 验证了命令路由，不执行训练。正式命令使用当前 Conda 环境的绝对 Python 和脚本路径，用户可一口气运行；如果系统重启、终端关闭或训练报错，修复外部问题后重新运行同一条命令即可从最近完成的 epoch 恢复。
