# 0008 — 排查隐藏输入未正确接收令牌的可能性

日期：2026-10-30（Asia/Shanghai）

用户重复复制后仍遇到 INPUT_FORMAT_ERROR。此错误来自本地输入检查，
还没有请求 Hugging Face；不能据此认定账号、模型权限或令牌已失效。
旧脚本没有区分空输入、前缀错误和空白字符，因此暂不能定位根因。

修改 login_huggingface.py：
- 失败时仅输出是否为空、前缀是否正确、是否包含非 ASCII、空白、
  控制字符或引号等布尔值，不输出令牌片段。
- 新增 --clipboard：由用户在自己的终端运行，并在提示后复制令牌、
  回到终端按回车，程序才读取本机剪贴板。绕开隐藏输入中的粘贴过程。
- PowerShell 子进程输出仅捕获到内存，不回显、不保存剪贴板内容到项目。
- 令牌继续仅发送到官方登录 API；登录后由 Hugging Face 库管理本机凭据。
- 本次开发验证只使用虚构字符串及模拟子进程，不读取真实剪贴板或真实令牌。
- 尚未获得用户重试结果，不声明登录问题已解决。
