# ConvNeXt-Tiny 阶段 B 后续：输入分辨率与空间池化 2×2 筛选

日期：2026-11-08（America/New_York）

## 背景与边界

原阶段 B 的锁定最终测试已经被查看，因此本轮属于后续探索性开发。测试集完全禁用，不能用于
训练、早停、模型选择或解释候选方案。即使未来再次在相同 93 张测试图片上评估，也不得称为
全新盲测。

阶段 B 四个确认种子的验证预测显示，主要稳定混淆为 `animal ↔ combined`。在 93 张验证图中，
78 张被四个 seed 全部识别正确，9 张被四个 seed 全部识别错误。部分稳定错图在 224×224
等比例缩放后，有效纹样高度仅为 35 或 59 像素；同时，原 ConvNeXt 全局平均池化可能削弱
组合纹中的次要局部成分。因此先比较输入分辨率与空间池化，不同时改变损失函数。

四个最佳验证 checkpoint 的合计混淆中，`animal → combined` 和 `combined → animal` 均为
8 次。反事实计算显示：如果只把这两个方向的错误全部修正，验证 Macro-F1 均值的理论上限
将从 `0.8733` 增至 `0.9120`（+0.0387）；若修正所有涉及 `combined` 的错误，理论上限为
`0.9331`（+0.0598）。这只是定位优化价值的上限分析，不是训练结果。

## 锁定 2×2 设计

| 方案 | 输入 | 池化 | 操作 |
|---|---:|---|---|
| B0 | 224 | 全局平均 | 复用已完成的 seed 42 验证控制，不重训 |
| B1 | 320 | 全局平均 | 训练 |
| B2 | 224 | `1×1 + 2×2` 空间金字塔 | 训练 |
| B3 | 320 | `1×1 + 2×2` 空间金字塔 | 训练 |

其余条件保持原阶段 B 不变：同一 434/93 开发划分、seed 42、只解冻 `features.7` 和分类头、
AdamW、stage 学习率 `1e-5`、head 学习率 `3e-4`、weight decay `1e-3`、batch size 16、
最多 50 轮、验证 Macro-F1 早停 patience 10、标准交叉熵。

空间金字塔将 `1×1` 全局特征和 `2×2` 四个局部特征拼接为 3840 维。分类器的全局 768 维
权重从阶段 A checkpoint 复制，四个局部分支权重初始化为 0。无更新预检已经确认：在 224 和
320 两种输入下，空间金字塔模型的初始 logits 与对应全局平均模型一致。这避免了随机更换分类头
造成的起点混杂。

## 预先锁定的选择规则

- 主指标：验证 Macro-F1。
- 候选至少比 B0 高 `0.005`，才进入多种子确认。
- 候选与最高值相差不超过 `0.002` 时，按计算量较低的 `B0 → B1 → B2 → B3` 优先。
- 本轮单 seed 结果只能用于筛选，不能直接宣称模型稳定提升。
- 选出的方案仍需多种子确认；本轮不评估测试集。
